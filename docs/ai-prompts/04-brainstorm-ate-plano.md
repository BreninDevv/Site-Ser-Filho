# Brainstorm até plano

## Quando usar

Pedido aberto (“melhorar o painel”, “deixar pagamento mais claro”) — antes de escrever código.

## Como usar

Cole no início da conversa.

## Prompt

```
Follow brainstorm → plan → implement for Ser Filho.

1) Clarify intent: ask questions until the goal is unambiguous (who, where in the site, success look like).
2) Propose a short plan with verifiable checks per step (build, page URL, SQL migration name if any).
3) Wait for my go-ahead.
4) Implement surgically; update CONTEXTO.md if business rules change.
5) Do not push to main unless I explicitly ask.
```
